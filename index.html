Section 06 · Not blind

Spring Boot Doesn’t Configure Everything Blindly

Condition 01

@ConditionalOnClass

Is the required class available?

@ConditionalOnClass(DataSource.class)
DataSource.class on classpath
🟢 Configuration can apply
Condition 02

@ConditionalOnMissingBean

Is the bean already available?

@ConditionalOnMissingBean
A custom bean already exists
🟢 Configuration can create it

Flip the switches — auto-configuration only applies when the conditions are met.

Section 10 · Recap

Four things to remember

01

Dependencies

Spring Boot checks what libraries are available on the classpath.

02

Auto-Configuration

Spring Boot configures the matching Spring components for you.

03

Conditions

Configuration applies only when classes and beans conditions are met.

04

Control

Exclude what you don’t want, and use --debug to understand what happens.

Remember

“Add the dependency, Spring Boot checks it, and configures what is needed.”
